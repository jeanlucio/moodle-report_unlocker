## English

The **Unlocker Report** is a Moodle course report for administrators and teachers. It displays
the **access restrictions** (availability conditions) applied to course activities and
resources in one searchable, filterable dashboard, with inline editing for all native core
restriction types plus PlayerHUD — instead of opening each activity's settings one by one.

📚 **[Full documentation](https://jeanlucio.github.io/moodle-report_unlocker/)** — features,
screenshots, the restriction type reference, integrations, the full test suite (82 PHPUnit
cases + a 25-scenario Behat suite) with coverage, and security details.

### 📦 Requirements

| Component | Version |
|-----------|---------|
| Moodle    | 4.5+    |
| PHP       | 8.1+    |

### 🛠️ Installation

1. Download the `.zip` file or clone this repository.
2. Extract the folder into your Moodle `report/` directory.
3. Rename the folder to `unlocker` (if necessary).
   Final path: `your-moodle/report/unlocker/`
4. Visit **Site administration > Notifications** to complete installation.

## Português

O **Relatório Unlocker** é um relatório de curso do Moodle para administradores e professores.
Exibe as **restrições de acesso** (condições de disponibilidade) aplicadas às atividades e
recursos do curso em um único painel pesquisável e filtrável, com edição inline para todos os
tipos nativos do core mais PlayerHUD — em vez de abrir as configurações de cada atividade uma
por uma.

📚 **[Documentação completa](https://jeanlucio.github.io/moodle-report_unlocker/pt.html)** —
funcionalidades, capturas de tela, referência de tipos de restrição, integrações, a suíte
completa de testes (82 casos PHPUnit + suíte Behat com 25 cenários) com cobertura, e detalhes
de segurança.

### 📦 Requisitos

| Componente | Versão |
|------------|--------|
| Moodle     | 4.5+   |
| PHP        | 8.1+   |

### 🛠️ Instalação

1. Baixe o arquivo `.zip` ou clone este repositório.
2. Extraia a pasta no diretório `report/` do seu Moodle.
3. Renomeie a pasta para `unlocker` (se necessário).
   Caminho final: `seu-moodle/report/unlocker/`
4. Acesse **Administração do site > Notificações** para concluir a instalação.
