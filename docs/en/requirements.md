# 📦 Requirements

| Component | Version |
|-----------|---------|
| Moodle    | 4.5+    |
| PHP       | 8.1+    |

No dependency on other plugins. Optionally detects and displays
[PlayerHUD](https://moodle.org/plugins/availability_playerhud)-based restrictions when
`availability_playerhud` and `block_playerhud` are installed.
